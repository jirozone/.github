# .github

Organization-wide defaults for jirozone repositories. GitHub uses a file here for any repository that has no file of its own, private ones included, so this repository has to be public. Keep secrets and internal detail out of it.

- `.github/pull_request_template.md`: the PR template every repository uses. How to fill it in: [writing.md](https://github.com/jirozone/engineering/blob/main/writing.md) (private).
